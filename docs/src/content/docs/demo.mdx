This is the same **drift** the [walkthrough](/fltr/walkthrough/) builds, compiled
to WebAssembly with Emscripten. It is the demo binary, not a re-implementation:
the identical source builds a native window on Windows, macOS and Linux, and CI
runs its headless smoke test on every commit.

**Arrows** or **WASD** fly, **space** fires, **escape** goes back and pauses, and
**tab** moves the focus. Click the canvas first: the keyboard goes to whatever
the page has focused.

The settings screen is worth a look. Interface scale multiplies every size the
theme hands out rather than stretching the finished frame, so text is rasterised
at the size it is drawn at instead of being an upscaled atlas. On a high-density
display the demo starts at the browser's own device pixel ratio.

<Aside type="caution">
  WebGL 2 and a keyboard. A phone will load it and draw it; flying a spaceship
  with no keys is another matter.
</Aside>
