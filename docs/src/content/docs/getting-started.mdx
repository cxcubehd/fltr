fltr is a retained-mode UI framework for embedding in a game engine. It ports
Flutter's architecture to C++23: the same three-tree split, the same layout
protocol, the same gesture arena, with no Dart, no garbage collector, and no
dependency on a graphics API.

## The bargain

fltr owns a widget tree, a render tree, and the pipeline that turns one into the
other. You own everything else.

| You own | fltr sees |
|---|---|
| The window, and whether it is fullscreen | A `Size` you push in |
| The clock, and how long the last frame took | A `float` you pass to `drawFrame` |
| The input system | `PointerEvent`, `KeyEvent`, `PointerSignalEvent` you dispatch |
| Fonts, shaping, and measurement | A `TextService` you implement |
| Textures | An opaque `ImageHandle` |
| The renderer | A `DisplayList` you translate |
| Game state | An `Observable<T>` you push into |

Nothing in that right-hand column is a plugin point fltr calls back into on its
own schedule. Everything happens because your loop asked for it.

## What one frame looks like

<Steps>

1. **Dispatch whatever input arrived.** Not part of the frame: an event goes in
   when it arrives, at whatever rate your platform produces them.

   ```cpp
   binding.dispatchPointer(event);
   const bool taken = binding.dispatchKey(key);  // false means it is the game's
   ```

2. **Push this frame's game state.** Pushing an unchanged value is a no-op, so
   this can be unconditional.

   ```cpp
   hull.set(ship.hull() / kHullMax);   // notifies nobody if it did not move
   ```

3. **Ask for a frame.** Animations advance, what is dirty is rebuilt, and what
   that made dirty is laid out and painted.

   ```cpp
   const fltr::Scene scene = binding.drawFrame(deltaSeconds);
   ```

4. **Submit what came out.**

   ```cpp
   submit(*scene.root);
   ```

</Steps>

<Aside type="tip" title="A frame that costs nothing">
Call `drawFrame` unconditionally rather than guarding it. A frame with nothing
dirty already does no work in any phase, and guarding risks getting the condition
wrong. If submission itself is expensive, compare `scene.revision` against last
frame's: unchanged means nothing anywhere was re-recorded.
</Aside>
