## Geometry

`fltr/core/geometry.hpp`. Every type here has a defaulted `operator==` and a free
`lerp(a, b, t)` overload — that overload is the ADL hook the `Interpolatable`
concept keys on, so every one of these can be animated.

```cpp
inline constexpr float kInf = std::numeric_limits<float>::infinity();
enum class Axis : std::uint8_t { Horizontal, Vertical };

inline constexpr float lerpF(float a, float b, float t) noexcept;
inline constexpr float lerp(float a, float b, float t) noexcept;
inline bool nearlyEqual(float a, float b, float eps = 1e-4f) noexcept;
```

### `Transform2D`

```cpp
struct Transform2D {
  float a = 1, b = 0, c = 0, d = 1, tx = 0, ty = 0;   // row-major 2D affine, 24 bytes

  static constexpr Transform2D identity() noexcept;
  static constexpr Transform2D translation(Offset) noexcept;
  static constexpr Transform2D scaling(float sx, float sy) noexcept;
  static Transform2D rotation(float radians) noexcept;
  static Transform2D aroundOrigin(const Transform2D&, Offset origin) noexcept;

  constexpr bool isIdentity() const noexcept;
  constexpr bool isTranslationOnly() const noexcept;
  constexpr Offset apply(Offset p) const noexcept;   // {a·x + c·y + tx, b·x + d·y + ty}
  Rect applyToRect(Rect) const noexcept;             // axis-aligned bounds
  constexpr float determinant() const noexcept;
  bool invert(Transform2D& out) const noexcept;      // false when degenerate
  constexpr Transform2D then(const Transform2D& m) const noexcept;   // this, then m
};
static_assert(sizeof(Transform2D) == 24);
```

<Aside type="note" title="Why 2D affine and not 4×4">
Hit testing must invert the transform *exactly* to map a global point into a
local one, and a 4×4 with perspective inverts only partially. Rotation, scale,
skew and translation are expressible; perspective is not.
</Aside>

## Observables

`fltr/core/listenable.hpp` and `fltr/core/observable.hpp`.

```cpp
class Subscription {                  // intrusive, allocation-free, move-only
  void detach() noexcept;
  bool attached() const noexcept;
  Listenable* source() const noexcept;
};

class Listenable {
  void subscribe(Subscription&, void (*fn)(void* ctx), void* ctx);
  bool hasListeners() const noexcept;
  std::size_t listenerCount() const noexcept;
protected:
  void notifyListeners();             // re-entrancy safe
};

class Notifier final : public Listenable { using Listenable::notifyListeners; };

template <class T, void (T::*M)()>
inline void subscribeMember(Listenable&, Subscription&, T* obj);
```

```cpp
template <class T> class ValueListenable : public Listenable {
  virtual const T& value() const noexcept = 0;
};

template <class T> requires std::equality_comparable<T>
class Observable final : public ValueListenable<T> {
  Observable();  explicit Observable(T value);
  void set(T next);        // an equal value notifies nobody
};

template <class T> requires std::equality_comparable<T>
class Animatable {         // a render property: a constant, or a source that shadows it
  const T& value() const noexcept;
  bool set(T next);                          // returns "needs invalidating"
  bool setSource(ValueListenable<T>* next);
};
```

## `Callback` and `FunctionRef`

`fltr/core/callback.hpp`, `fltr/core/function_ref.hpp`.

```cpp
template <class R, class... Args> class Callback<R(Args...)> {
  static constexpr std::size_t kCapacity = 4 * sizeof(void*);   // 32 bytes
  Callback() = default;
  template <class F> Callback(F&& f) noexcept;    // copies into inline storage
  explicit operator bool() const noexcept;
  R operator()(Args...) const;
};

template <class R, class... Args> class FunctionRef<R(Args...)> {
  FunctionRef() = delete;
  template <class F> FunctionRef(F&& f) noexcept;   // non-owning
  R operator()(Args...) const;
};
```

<Aside type="caution" title="Callback captures must be trivially copyable and ≤ 32 bytes">
Both are `static_assert`s. A `Callback` captured inside another `Callback`
overflows the budget — pass a function pointer plus a `void*` owner instead.
</Aside>

## `Key`

`fltr/core/key.hpp`.

```cpp
struct Key {
  enum class Kind : std::uint8_t { None, Int, Str };
  static constexpr Key none() noexcept;
  template <class T> requires std::is_integral_v<T> static constexpr Key of(T) noexcept;
  static Key of(const char* s) noexcept;    // FNV-1a hash + strcmp fallback
  constexpr bool isSet() const noexcept;
  std::uint64_t hashCode() const noexcept;
};
```

A string key stores the **pointer** and a hash, so the storage must outlive the
element. Literals are the intended case.

## Contracts

```cpp
class ContractViolation : public std::logic_error { ... };

namespace detail {

                                    const char* file, int line);
```
